# Introduction
2020年代に入り、大規模言語モデル（LLM）を中心とした生成AIは、社会のさまざまな分野に急速な変化をもたらしている。
そのトレンドは地理空間情報分野にも及び、日本でも行政・研究・民間の各領域で、AIのGISへの適用が進んでいる。

しかしながら、言語・画像による現状の生成AIだけでは、地理空間情報の分析は難しいとされている。[^1]
その理由として、地図を読むことは他人が描いた高密度かつハイコンテクストな文脈を読み解く行為であること、そして技術的には地図、衛星画像、点群、時系列といったマルチモーダル情報を、いかにAIが読める形にするかが課題であると言われている。[^2]

そのため近年、日本では国土交通省と内閣官房が主導するGeoAI研究会[^3]や、人工知能学会のGeoAIセッション[^4]、GIS関連コミュニティでの研究発表などを通じて、GIS x AIに関する具体的な取り組みが急速に増えている。

そこで本記事では、日本におけるGIS x AIの現在地（2026年時点）について、実務と政策の観点から整理する。

# 日本におけるGIS x AIの状況
2026年現在、日本におけるGIS x AIの特徴的な動きとしては、国土交通省および内閣官房が主導する「ジオAI研究会」の発足[^3]、行政機関および民間企業によるGISサービスでの生成AIの活用があげられる。

## GIS x AIの分類
ジオAI研究会において、地理情報とAIのコラボレーションには、AI for GIS、GIS for AIという両方の視点が言及されており、これらはそれぞれ下記の通り定義されている。[^5]
- AI for GIS: AIによってGISの活用を容易にすること
- GIS for AI: 空間関係を理解してAIが実社会の予測と行動の提案まで行うこと

また、ジオAI研究会では、将来的に日本が目指すべきは「GIS for AI」の社会実装であるが、現在は「AI for GIS」が先行している状況であると指摘している。[^5]

さらにこのうち、AI for GIS、つまり地理情報システムをAIで扱うという目的において、現状は下記のパターンに分類できると筆者は捉えている。

- GIS操作エージェント：主にチャット形式によるAIエージェント（アシスタント）を通じて自然文でGISソフトを操作し、データ取得・可視化・分析・意思決定を支援する。
- GISデータ解析：ユーザーが特定地域やテーマを指定して、そこに関連づけられたレイヤ情報を統合的にAIが把握して分析する。
- GISデータ生成：衛星データや航空写真などからAIを用いて地物を自動抽出し、ベクターデータなどに変換する。
- GIS-AI接続基盤：各種AIサービスとGISサービスを接続するためのソフトウェア及びデータ基盤を提供する。

## 民間GISサービスのAI活用事例
日本の民間企業においても、上述のAI for GISの事例は増えてきている。
例えば、日本の大手GIS企業は衛星データや航空画像とAIを活用したモニタリングのサービスを提供している。

具体的には、測量技術に定評のある株式会社パスコは、衛星データとAIで地形変化を検出するサービス「Mieteru盛土」を2025年から提供し始めた。[^6]
また、その競合であるKokusai Kogyo株式会社は他の研究機関と共同して、ドローン撮影画像から土砂災害を専門家レベルで分析するマルチモーダルAIシステムを開発している。[^7]

*専門家レベルで土砂災害を分析するマルチモーダルAIシステム（出典：国際航業株式会社）*

![衛星データによる地形変化検出 by PASCO](/images/articles/eita-h/eh_geoai_image03.webp)
*衛星データとAIで盛土の崩壊リスクを監視する「Mieteru盛土」（出典：株式会社パスコ）*

また、以前の記事で紹介した"open-hinata3"では、ウェブ地図アプリケーション上で700種類以上のレイヤをもとに、特定地域の状況を自動的に解析したり、AIエージェントに質問を行うことが可能となっている。[^8]
同様に、LocationAIなどのいくつかの位置情報企業も、独自のデータ分析プラットフォームにAIチャット機能を組み込んだサービスを展開している。[^9]
また、GISxAIの基盤として、Geoloniaが行政向け都市OSを開発している。[^10]
さらにユニークな取り組みとしては、ジオテクノロジーズ株式会社はAIを活用した研究開発向けに道路標識などのオープンデータにて無償公開している。[^11]

## 行政GISサービスのAI活用事例
同様に、国や自治体が展開するAI for GISサービスも増えてきている。それらはGIS x AIの基盤づくりが中心である。
代表的な動きとして、国土交通省は2026年、「地理空間MCP Server-MLIT Geospatial MCP Server-」（α版）を公開した。これは、不動産情報ライブラリという不動産取引に関するデータ提供サービスにおける25種のデータセットをAIを通じて利用可能にする。[^12]

また、JAXA（宇宙航空研究開発機構）は、衛星データをAIを通じて取得・解析するためのMCPサーバを提供している。[^13]
さらに、国が展開する3D都市モデルPLATEAUのデータ更新において、AIを活用した地物の自動抽出や更新の実証実験が進められている。[^14]

## 国のジオAI研究会での検討状況
国交省・内閣官房の「ジオAI研究会」は2026年に開始された国の検討委員会である。[^3]
本記事執筆時点では4回の会議が実施されており、その中間報告から得た要点を下記にまとめる。[^5]
 
- 将来的に目指すべきは、空間関係を理解して予測提案まで行うGIS for AIの社会実装。
- その上で、AI-readyなデータ整備がボトルネックであり次の論点となる。
- そのため、全国汎用で使えるモデル整備に向けた、教師データの流通基盤整備が中核となる。
- 日本が強みを出せる基盤的な領域として、GISと生成AIを結びつけるための「空間オントロジーの整備」があげられる。

この報告書は、今後の日本における地理空間情報xAIの戦略を定める指針として注目されている。
2026年6月に公開された「第５期 地理空間情報活用推進基本計画骨子（案）」においても、地理空間情報とAIの統合が基本方針の一つとして掲げられている。[^15]

# 日本におけるGIS x AIの課題
一般的な話として、地理空間情報にはラスターとベクターの地図データ、3次元データ、衛星画像・航空写真、座標値、座標系、トポロジー、位置関係、時系列といったものが含まれる。
GIS x AIの実現を難しくしている大きな理由は、AIがこれらの複雑な情報を統合的に解釈する必要があることだろう。
2026年現在の時点では、この課題の解決手法として地理空間情報に特化したモデルが必要になるか、また、どのような空間データやオントロジーの整備が必要となるか、といった議論もまだ進行中である。[^5]

さらに、GIS for AIの運用ルールやガバナンスも議論の余地が大いにある。例えば防災GISなどにAIを活用した際、人命に関わる意思決定をAIに任せることができるか、といった話が議論されている。[^5]
また、2026年5月に発表されたジオAI研究会の中間報告では、AI readyな地理空間データの整備がボトルネックになっていることが指摘されている。[^5]
一方で、GISオントロジーの整備は日本において強みでもあるため、このボトルネックは日本の国と民間企業にとって大きなチャンスとも言えるだろう。
